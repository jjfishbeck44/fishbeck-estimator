# Rehab Calculator — User Flows

1. Enter property basics (size, condition, scope areas).
2. Select work items per area.
3. Tool computes quantities → applies pricing/production rates → returns budget range.
4. User exports/share or books a consult (lead handoff to Fishbeck).
